# User Stories

## User

- As a user, I want to be able to visit different quiz sets, so that I may study them.
- As a user, I want to authenticate, so that I can save my favored quiz sets.
- As a user, I want to be able to use flash cards from quiz sets, so that I can study.
- As a user, I want to be able to learn using flash cards and fill in the blanks, so that I can study.
- As a user, I want to be able to use quiz sets and test myself on them, so that I can study.
- As a user, I want to be able to host game shows, so that I can learn and compete with friends.
- As a user, I want to be able to report inappropriate quiz sets, so that I can keep the website safe.

## Creator

- As a creator, I want to be able to create quiz sets, so that I can study.
- As a creator, I want to have the option to edit questions and answers, so that I can keep my quiz sets up to date.
- As a creator, I want to share links to others, so that I can share my quiz sets for others to study.
- As a creator, I want to provide optional test answers, so that my tests are more authentic.

## Admin

- As an administrator, I want to be able to delete quiz sets, so that rules can be followed.
- As an administrator, I want to be able to edit quiz sets, so that rules can be followed.
- As an administrator, I want to be able to view reported quiz sets, so that I can respond to users' reports.
